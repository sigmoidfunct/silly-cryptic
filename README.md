# Minute Cryptic

A simple 10-question cryptic-clue web game inspired by the clean, minimal style of daily puzzle sites.

## Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — 10 clues, answer checking, hints, explanations, and navigation

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's **Settings → Pages**.
4. Under the deployment source, select the `main` branch and `/ (root)`.
5. Save.
6. GitHub will provide a public Pages link.

No database or account system is used. Nothing is saved between sessions.
